# Native release cleanup — 2026-10-08

The active product is local hybrid RAG with compact summaries, embeddings, lexical matching and model-based relevance selection. The older Postgres pipeline and experiments are separate implementations, not additional stages of the native flow.

## Changes

- The installed `logchat` entry point is `cli.native:app`: install, start, local and settings. Historical account/stack commands no longer appear in the public command tree.
- Generated native MCP integrations use the same native entry point.
- Standard setuptools packaging replaces the custom build that embedded an entire second Docker stack in every wheel.
- Makefile installation, lifecycle, testing and build defaults use the native application. Historical Docker targets are explicitly named `legacy-*`.
- Docker and Compose files explicitly identify their historical purpose.
- The wheel audit checks the native entry point and rejects embedded historical stacks.
- The public source export includes Makefile and hosting boundaries, and excludes local state, generated builds, media and historical reports by allowlist.

## Preserved work and limits

No memory databases, credentials, original log files, recordings, marketing edits or educational HTML edits were removed. Historical code is retained in the development source because it provides regression/migration coverage and native modules still share some contracts with it. This is release-path cleanup, not a claim that every historical module has been deleted.

Online hosting scope must be selected before deployment: a public website with locally installed Logchat, a private persistent service, or a new public multi-user service. See hosting.md. No service has been exposed publicly by this cleanup.

## Verification

- Regression suite: 626 passed, 177 subtests passed, one opt-in real-embedding test skipped; two existing Typer/Click deprecation warnings.
- Native UI contracts passed.
- Wheel audit: 71 shipped module/asset files match source; native entry point verified; embedded `_stack` absent.
- Initial wheel shrank from 562,936 bytes (rc11) to 257,594 bytes (rc12), about 54% smaller. This measures package size, not memory-retention compression.
- Archive structure checks passed. Final artifacts are rebuilt from the clean public export so updated hosting documentation is included.
